# AssetHub Product Roadmap

## Completed baseline

- Tenant and System Admin console separation.
- PostgreSQL/Prisma migration baseline.
- Asset inventory, lifecycle, assignments and transfers.
- Organization hierarchy management.
- Tenant users/employees and RBAC.
- System tenant management and Tenant 360.
- Plans, subscriptions and entitlements.
- Platform users and roles.
- Identity/SCIM feature gating.
- Shared form/modal/button/loading components.
- Notification deduplication baseline.
- Frontend/backend wiring hardening.

## Current hardening

- Page-by-page frontend/backend regression testing.
- Authorization and tenant-isolation validation.
- API contract regression tests.
- Migration/deployment verification.
- Search/filter performance validation.
- UI consistency and accessibility checks.

## Next product increments

- Expanded automated end-to-end test coverage.
- More comprehensive notification preferences and delivery policies.
- Advanced identity lifecycle workflows.
- Richer analytics and operational dashboards.
- Additional import/export automation.
- Optional MFA/stronger authentication capabilities.

## Longer-term

- More integrations and automation.
- Advanced compliance/reporting packages.
- Expanded asset discovery and reconciliation workflows.
- Broader platform observability and customer self-service.
